Installing on Android: open the downloaded file and allow installs from your browser when asked. The app is signed with the Clavium release key, SHA-256 {{APK_CERT}}.

Web app on iPhone: open it in Safari, tap Share, then Add to Home Screen. On Android Chrome, tap Install app.

Windows: the installer is not code-signed yet, so SmartScreen may warn on first run. Choose More info, then Run anyway.

Already use Clavium? Choose "I already use Clavium" on first launch and sign in to bring your vault across.
